# Pierre Dark

[Pierre Dark](https://pierre.computer) (the standard dark palette) for [Omarchy](https://omarchy.org),
ported from the official [Pierre theme](https://github.com/pierrecomputer/theme).

## Install

In Omarchy, go to **Install > Style > Theme** and paste:

```
https://github.com/douglasdemoura/omarchy-pierre-dark-theme
```

## All Pierre themes for Omarchy

- [Pierre Dark](https://github.com/douglasdemoura/omarchy-pierre-dark-theme) **(this repo)**
